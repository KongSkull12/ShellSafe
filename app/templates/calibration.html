Calibration

Put the probe in the solution, wait until its signal stops changing, then run the step. The device takes about 2 seconds to measure and saves the result in its own memory, so it survives restarts.

The device is not live. Calibration steps run on the device itself, so it must be powered and online over WiFi.

{{ probe_head('ph', 'pH', 'Signal') }}

1. pH 7.00 buffer

Rinse the probe with clean water, put it in the pH 7.00 buffer and wait 1–2 minutes.

{{ run_button('PH7', 'Calibrate pH 7.00') }}

2. Second buffer

Rinse again, then use the pH 4.00 buffer (or pH 10.00 if that is what you have). pH counts as calibrated after both steps.

{{ run_button('PH4', 'Calibrate pH 4.00') }} {{ run_button('PH10', 'pH 10.00', quiet=True) }}
{{ result_box('ph') }}
{{ probe_head('ec', 'EC', 'Signal') }}

1. Dry zero (optional)

Rinse and dry the probe and hold it in the air. Only needed if the signal in air is above about 0.02 V.

{{ run_button('EC0', 'Set dry zero', quiet=True) }}

2. Conductivity standard

Put the probe in the standard and wait until the reading stops changing. Enter the value printed on the bottle.

{{ probe_head('turbidity', 'Turbidity', 'Signal') }}

1. Clean water

Put the probe in clear water so the gap between the prongs is filled. This sets 0 NTU.

{{ run_button('TURB0', 'Set 0 NTU') }}

2. Turbidity standard (optional)

Sets the NTU scale. Without it, readings above 0 use an estimated scale.

{{ value_field('calTurbValue', 'Standard', 100, 'NTU', 0.1, 4000) }} {{ run_button('TURB', 'Calibrate scale', 'calTurbValue', quiet=True) }}
