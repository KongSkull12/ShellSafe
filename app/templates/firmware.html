Before you start

        

        
    
            
  • Close Arduino IDE's Serial Monitor and any other app using the port. Only one program can hold it.
    • 
            
  • If it says "wrong boot mode", hold the board's BOOT button, tap RST/EN, release BOOT, then press Flash again.
    • 
            
  • An update keeps calibration. It only replaces the app, so saved pH, EC and turbidity calibration stays on the device.
    • 
            
  • Don't unplug while flashing. If it's interrupted, just flash again. The board can always be recovered over USB.
    • 
        

        
Build a new .bin with python build_firmware.py on the computer that has secrets.h. The file contains your WiFi and Firebase credentials, so don't share it or commit it.
